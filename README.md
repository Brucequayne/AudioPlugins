# AudioPlugins

Eigene Audio-Plugins. Jedes Plugin hat einen eigenen Ordner.

| Plugin | Was es macht | Download |
| --- | --- | --- |
| [Earrection](Earrection/README.md) | 8×8-Effektmatrix (Stutter, Repeat, Reverse, Tempo, Echo, Gate, Filter, Klang), per Maus oder Ableton Push spielbar | [Neuester Build](https://github.com/Brucequayne/AudioPlugins/releases/tag/earrection-latest) |

Die Plugins werden bei jedem Hochladen automatisch von GitHub für Windows und Mac gebaut (Reiter **Actions**). Die fertigen Dateien liegen unter **Releases**.
